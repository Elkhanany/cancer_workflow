        Advanced: open a Merge Request on GitLab
        

          
For users comfortable with GitLab. This commits the change to a new branch and opens a merge request against main — no terminal required. Merging it redeploys the site through Cloudflare Pages automatically.

          

            
Token safety. Paste a GitLab personal access token with the api scope — GitLab requires that scope for a classic token to create merge requests. It grants access to every project your account can reach, so give it a short expiry date. It is stored only in this browser's localStorage and sent only to gitlab.com over HTTPS, in a request header. It is never placed in a URL or logged. Use Forget token on a shared device.

            
Safer alternative: a fine-grained personal access token limited to a.elkhanany/cancer_workflow with Repository: Read, Commit: Create and Merge Request: Create.
